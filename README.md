# Medivanta Pharmaceuticals — Corporate Web Application

> **“Advancing Healthcare. Improving Lives.”**

A premium, modern, fully responsive web application developed for **Medivanta Pharmaceuticals**, a leading Indian pharmaceutical manufacturer and international exporter. This platform is engineered to B2B enterprise standards for institutional healthcare clients, authorized distributors, hospital chains, and global procurement ministries.

---

## 🏛️ Brand System & Corporate Aesthetic

- **Color Palette**: Deep Navy Blue (`#07182E`, `#0B2545`), Precision Medical Blue (`#0284C7`), Modern Bio-Teal (`#0D9488`, `#06B6D4`), and Clean Slate Grays.
- **Typography**: Google Fonts **Plus Jakarta Sans** and **Inter** for corporate, scientific legibility.
- **Visual Design**: High white space ratio, rounded cards with subtle drop shadows, glassmorphism sticky navigation, and verified high-resolution pharmaceutical laboratory and cleanroom imagery.
- **B2B Tone**: Structured for enterprise procurement, tender participation, contract manufacturing (CDMO / loan licensing), and international export licensing.

## 🔬 Core Highlights

- **Interactive Product Modal**: Detailed technical dossiers with primary packaging, shelf life, storage conditions, therapeutic segment, CTD/ACTD dossier status, and direct enquiry auto-fill.
- **Global Presence Map**: Interactive SVG map with glowing markers and regional spotlights for South Asia, MENA, Africa, ASEAN, and CIS markets.
- **Universal B2B Enquire Modal**: Instant lead capture with reference tracking code generation (e.g. `MV-B2B-849201`).
- **Production-Ready & Fully Typed**: Zero TypeScript compiler errors, fast Vite bundling (1.3s), and responsive mobile drawer navigation.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Routing**: React Router DOM v7
- **Fonts**: Plus Jakarta Sans & Inter

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm (v9+)

### Installation

```bash
# Clone the repository
git clone https://github.com/shamshadkhan36/Medivanta-Pharmaceuticals.git

# Navigate into the project directory
cd Medivanta-Pharmaceuticals

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build

```bash
# Compile TypeScript and build production bundle
npm run build

# Preview production build locally
npm run preview
```
